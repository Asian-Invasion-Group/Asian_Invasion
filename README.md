# Lifestyle Levelling

This ***Lifestyle Levelling project*** is part of CAB302 Agile Project Development at Queensland University of Technology. Our team, **Asian Invasion** — [Jammie Chen](https://github.com/Jammie-C), [William Qu](https://github.com/willisepic21), [Brooklyn Diep](https://github.com/BD5799), [Hui Colin Wu](https://github.com/Ka-319), and [Mingyuan Lyu](https://github.com/Mingyuan220) — worked together on everything as equal contributors. We’re all about keeping things simple and practical, building an app that makes it easy to track groceries, electricity use, and weather‑based habits without any fuss. 

---

## Executive Summary
- Reduce grocery waste by tracking stock levels and expiry dates  
- Monitor electricity usage using monthly bill inputs and provide reduction recommendations  
- Use a Weather API to recommend optimal days for drying clothes and walking for better health  

---

## Project Objectives
- Decide on UI screen designs  
- Create user stories  
- Integrate Weather API functionality  
- Build a unified, easy‑to‑understand application design  

---

## Needs Statement
- People need a easy way to track sustainability in their current lifestyles. 
- Current solutions involve complex diagrams, separate apps and even using third party services  
- With no centralised way to track their progress to achieve their sustainability goals. 
- To improve sustainability goals, people need a simple and centralised app that is easy to use and understand that makes it convenient to improve lifestyle. 

---

## Project Scope
A simple, easy to use Java based JavaFX application for desktop users that allows a user to monitor their sustainability goals by keeping track of grocery and expiry dates, recommending ingredients to use base on their shelf life. Furthermore, the app can keep track of electricity usage and compare it with an electric bill to identify and reduce usage. Improvements and recommendation can be used from Weather API to identify sunny days to utilise natural energy 

---

## Requirements
- Simple and friendly GUI  
- Database to keep track of current groceries   
- Graphs/visualised data for electricity usage  
- Pull data from Weather API and identify sunny days and intervals between sunny days
